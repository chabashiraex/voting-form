【注意点】
・Googleアカウント認証が完了すると、はじめにペンネームを選ぶページが出ます。そこで自分のペンネームを選んでください。（間違えると修正できないので必ずちゃんと自分の名前を選んでください）
・「前期」「中期」「後期」で作品一覧が出ます。自作以外の点数を投票できるようになっているので、可能な限り各作品を投票してください。
・一番下にある「一時保存」ボタンで保存ができます。「一時保存」しそこねると、セーブされないのでお気をつけて。
・「後期」のページにある「投票完了」ボタンを押したら投票は完了です。これを押すと、そのアカウントで以後投票ができなくなります。
・多少の崩れはありますがスマホでも見れるし投票できます
・結果発表は全員投票が終わったら公開されるようになるはずですが、ここだけ挙動確認できてないので投票が終わったらおいおい確認します。
